Belavadös player view-only pages

Locked across player pages:
- code/HTML downloads
- code/image/file uploads outside approved player portal import/export
- map/globe JSON import/export tools
- scan terrain/scanning tools
- source/code viewing buttons
- editor/save/delete controls
- character sheet art/alignment uploads and sheet field editing

Allowed exceptions preserved:
- alignment quiz interaction and result JSON export
- character sheet JSON/PDF/print exporting
- character generator interaction and sheet/PDF exporting
- player portal importing/exporting/uploading player sheet files

Note: browser-level actions such as Save Page As are controlled by the browser, not by page JavaScript. These files remove or block the in-page controls that expose code, uploads, scanning, editing, or unauthorized downloads.
