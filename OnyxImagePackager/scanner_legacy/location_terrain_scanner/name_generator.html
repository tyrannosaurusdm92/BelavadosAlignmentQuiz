Belavadös Settlement Name Generator

Embed-ready asset for settlement generators. It reads racial data from JSON, creates enough NPC names for the requested population, and returns name, race, gender identity, and pronouns for interactive map display.

Asset usage: include name_generator.js, then call BelavadosNameGenerator.generateNPCs(settlementData) from your settlement generator. This HTML file provides an optional in-generator panel and demo harness.
