# Onyx task versions

These are lightweight entry pages that open the same clean image-composition engine with a task-specific note:

- `onyx_biome_creator.html` — general biome composition.
- `onyx_settlement_composer.html` — building-heavy settlement layout composition.
- `onyx_asset_auditor.html` — asset naming and category inspection.

All versions use the same CSS, JavaScript, JSON profiles, Onyx persona files, and `assets/map_assets` folder.
