OnyxImagePackager biome interactive map builder merge

Merged in:
- coordinate-tracking Belavadös interactive map builder templates
- hidden biome location library JSON
- selected capital/city/town/village template export
- selected biome JSON profile export
- biome_location_generation_plan.json export
- settlement scale targets for locations, named NPCs, and world travelers

Export behavior:
- capital requests include capital_city_map_builder_template.html
- city requests include city_map_builder_template.html
- town requests include town_map_builder_template.html
- village requests include village_map_builder_template.html
- full builder program is also included under template_program/interactive_map_builder/
- selected request bundle is included under selected_interactive_map_builder/

Biome split behavior:
- 1 selected biome: 100%
- 2 selected biomes: 50% / 50%
- 3 selected biomes: 33.33% / 33.33% / 33.34%

Example:
Capital + Underwater with reefs + Ocean Surface floating settlement + Beach and grass with water:
- Underwater with reefs: 33.33%, 437 of 1,312 location slots
- Ocean Surface floating settlement: 33.33%, 437 of 1,312 location slots
- Beach and grass with water: 33.34%, 438 of 1,312 location slots
