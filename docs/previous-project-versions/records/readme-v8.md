# TableGate Campaign Studio v8

Version 8 embeds the Auto XP & Advancement Wizard editions of all nine character sheets. It adds downloadable full character art and token exports, responsive portrait/landscape layouts, and a 72-hour player-consent workflow for runner-created private linked copies.

## Runner-copy consent

A DM, GM, MOL, Master of Lore, Storyteller, Keeper, Referee, or equivalent creator may request a private linked copy of a player-owned character. The player has 72 hours to approve. Pending copies are permanently removed at expiry or immediately on rejection. Approved copies may contain runner-only secrets and rumors. Entries become player-visible only when the runner explicitly reveals them. The player may revoke approval and delete the linked copy later.

The original player character is not edited by this workflow. Runners are prevented from using the normal edit/delete buttons on another player's character and are directed to the consent-copy workflow instead.

## Artwork

Every embedded and standalone sheet offers downloads for Full Art 1, Full Art 2, the cropped token, and all available art. The campaign vault also exposes artwork downloads per saved character.

## Responsive layouts

The nine sheets include dedicated rules for mobile portrait, tablet portrait, mobile landscape, tablet landscape, and desktop widths. Controls wrap, sidebars unstick on compact portrait displays, art uploaders scale to the viewport, and landscape layouts use available width without hiding fields.
