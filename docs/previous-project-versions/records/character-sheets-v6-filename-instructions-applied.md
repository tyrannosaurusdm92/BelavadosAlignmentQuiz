# Filename Instruction Audit

The root filenames were read as implementation instructions before revising the sheets.

## `copy hamburger navigation and 2 image uploader and narrow overlay from here.html`

Applied to all nine sheets:

- 75 px draggable circular hamburger button;
- left-side floating placement with responsive mobile fallback;
- generated jump-section dropdown and Go control;
- narrow centered 960 px overlay;
- two persistent artwork upload windows;
- click and drag-and-drop image handling;
- mobile and print behavior adapted from the reference.

## `copy color schemes (without copying homebrew names like ichor) from here.html`

Applied to all nine sheets:

- cyan, teal, copper, parchment, navy, steel, and violet palette values;
- synchronized named design selector in the header and hamburger panel;
- user-editable colors and backgrounds.

Explicitly not copied:

- Belavadös or any other world name;
- ichor terminology;
- deity, faction, settlement, skyship, bestiary, or campaign-hub names;
- homebrew mechanics or lore.
