# TableGate Campaign Studio v8 — Four-Part Package

Extract all four ZIP archives into the same parent directory and allow the shared `TableGate_Campaign_Studio_v8` folder to merge. The four archives contain disjoint file paths and are not intended to be concatenated. Open `tablegate.html` from a static HTTPS host after extraction.

The runnable project contains exactly one HTML file. Root support files are `service-worker.js` and `manifest.webmanifest`; all folders are `assets`, `css`, `docs`, `js`, and `json`.
