# Historical Source Archive Record

Earlier TableGate releases retained original user-supplied archives as numbered chunks. The unified v9 release does not ship those superseded executable archives.

This document remains only so that historical validation files mentioning `docs/source-archives/` are understandable. Those paths describe earlier releases and are not required to run, inspect, reconstruct, test, or redistribute the current unified source.

Current reproducibility evidence is provided by:

- `MERGE_AUDIT_v9.md`
- `PACKAGE_MANIFEST_v9.json`
- `TEST_REPORT_v9.md`
- `LICENSE_AND_PROVENANCE_v9.md`
- `json/source-provenance.json`
- `licenses/`
- `source-readmes/`
- `source-code/`
