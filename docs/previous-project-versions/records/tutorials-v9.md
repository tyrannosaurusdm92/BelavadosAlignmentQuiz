# Campaign-Runner Tutorials

Created By William Saville AKA The Transgender T-Rex #TheTransgenderTrex developer of Belavadös Galaxy TTRPG System

TableGate offers a tutorial chooser the first time a campaign runner opens a campaign workspace. It applies equally to DM, GM, MOL, Master of Lore, Storyteller, Keeper, Referee, and equivalent titles.

Tutorials are available for:

- campaign setup
- Campaign Hub
- Effects Studio
- World and Life Studio
- Virtual Tabletop
- Session Dice
- characters
- messages, voice, and safety
- Organizer and Calendar
- publishing and player access
- documentation and sources

Campaign runners may select individual guides, select all, select none, review completed guides, reset progress, or disable tutorials entirely. The enabled state, selected tools, offer state, and completion records are stored per user. Disabling tutorials suppresses future prompts; it does not disable any TableGate tool.

## Session Dice guide

1. Open Character Sheets and choose **Play** on an already completed saved character.
2. Confirm that the character name, filled sheet, and one of the nine supported game systems appear inside Session.
3. Choose the roll color that players and administrators should see.
4. Roll from the outer controls, a character-sheet action, a system quick action, or the dice bot.
5. Include an explicit modifier, target, pool, or trait die when the filled sheet does not make it unambiguous.
6. Select a campaign text channel before a public roll so the exact result becomes a durable shared event.
7. Use Private Dice for hidden campaign-runner checks. Select an admin channel only when that result should be shared with administrators.

The supported systems are Fate Core, GURPS Fourth Edition, Call of Cthulhu Seventh Edition, Daggerheart, Pathfinder Second Edition Remastered, Powered by the Apocalypse, Savage Worlds Adventure Edition, Blades in the Dark, and D&D 5e / 5.5e.
