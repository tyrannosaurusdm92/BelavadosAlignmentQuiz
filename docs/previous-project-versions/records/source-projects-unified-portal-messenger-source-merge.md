# Source merge map

- **TTRPG Messenger Merged** supplied the working single-page Apps Script client, server rail, channels, DMs, messages, member roles, dice personas, and WebRTC signaling foundation.
- **OurSpace Household Organizer classic** supplied the task-board, month-calendar, agenda, quick-capture, and responsive organizer interaction patterns. Household-specific rewards, household branding, DBT/ADHD categories, shopping, and unrelated personal modules were removed or repurposed.
- **discord-clone-master** and **discord-clone-main** informed the channel/member layout, modal workflows, mobile sidebar, server actions, message actions, file upload, member management, and media-room behaviors.
- **ZeusIX** informed richer desktop-style navigation, notification sounds, call controls, presence, push-to-talk, screen sharing, profile/settings treatment, and app-install orientation.

The original uploaded archives are preserved under `assets/source-archives` for auditing. They are not executed by the application.
