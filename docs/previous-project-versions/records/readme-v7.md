# TableGate Campaign Studio v7

Open `tablegate.html` from a static HTTPS host. The project continues to use one HTML file, the five folders `js`, `css`, `json`, `docs`, and `assets`, plus the root service worker and web manifest. No Windows batch files are required.

## v7 additions

- Universal JSON, TXT, DOCX, and PDF character import.
- Import controls inside all nine embedded sheets and the campaign Character Vault.
- Direct porting of an existing saved character to another sheet system.
- Same-system full-state preservation.
- Cross-system canonical conversion with visible substitutions and preserved unmapped source data.
- D&D-to-Pathfinder legal-option helpers.
- D&D race/option stale-state repair and nine-sheet selection regression checks.

See `UNIVERSAL_CHARACTER_IMPORT_AND_PORTING.md` and `SELECTION_STATE_AUDIT_v7.md` for the detailed behavior and limits.
