# Code Provenance and Showing-the-Work Policy

Created By William Saville AKA The Transgender T-Rex #TheTransgenderTrex developer of Belavadös Galaxy TTRPG System

The machine-readable catalog is `json/source-provenance.json`; TableGate renders it in **Data & Sources**. The **Docs** view also indexes current release evidence, retained upstream notices, licenses, source READMEs, historical audits, and manifests.

Every catalog entry is classified as:

- **Integrated** — code or assets are present, or an identified algorithm was adapted. Local paths and licenses are recorded.
- **Reference** — the project informed research or interface/algorithm concepts, but no code was copied.
- **Excluded** — the project was reviewed but not redistributed, generally because rights were unclear, protected game text was present, or its architecture did not fit the browser target.
