# Reconstructing TableGate Campaign Studio v6

The release is distributed as four independent ZIP archives. Extract all four archives into the same parent directory and allow their shared `TableGate_Campaign_Studio_v6` directory to merge.

Do not concatenate the ZIP files. No file path is duplicated between parts.

After extraction, open `TableGate_Campaign_Studio_v6/tablegate.html` from a static HTTPS host. The application requires no Windows batch files or build command.

Use the external `TableGate_Campaign_Studio_v6_PACKAGE_MANIFEST.json` and `TableGate_Campaign_Studio_v6_SHA256SUMS.txt` to verify the downloaded archives. The internal `docs/manifests/BUILD_MANIFEST_v6.json` lists project-file hashes.
