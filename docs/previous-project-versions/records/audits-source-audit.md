# Source Integration Audit

## Directly retained from the supplied TableGate project

The single-page messenger shell, backend API client, authentication, server/channel UI, direct messaging, permissions, dice/personas, WebRTC voice/video, organizer, calendar, rules library, PWA bootstrap, JSZip, campaign banners, icons, and notification sounds were retained and extended. The entry file was renamed to `tablegate.html` and backend references were updated to the supplied deployment and library version 5.

## Fantasia Archive (GPL-3.0)

Reviewed for world database concepts: project hierarchy, article templates, tags, relationships, document preview, import/export, and project management. No Vue, Quasar, Electron, TypeScript, or Fantasia source file was copied into the browser build. The new implementation is original plain JavaScript. GPL text and upstream README are preserved in `docs`.

## Obsidian TTRPG Share (MPL-2.0)

Reviewed for system-neutral vault organization and linked-note conventions. No repository source file or template body was copied. The MPL text and README are preserved.

## Obsidian WWN / SWN Markdown

Reviewed only for vault organization and link conventions. Game text was deliberately excluded because the repositories include Sine Nomine notices and noncommercial terms. Their license/notices and README files are preserved for audit.

## MythKeeper

Reviewed for asset gallery, profiles, import/install queue, filtering, and preview concepts. No license file was found in the supplied archive, so no MythKeeper code, fonts, images, or other assets were copied. Its README is preserved.

## Template Share

Reviewed for the idea of reusable worldbuilding templates. No license file was found, so no template prose or repository file was copied. TableGate’s generic templates were independently written.

## Logseq docs archives

Reviewed for graph, references, whiteboard, Markdown, import/export, and portable graph concepts. Large media and documentation text were not redistributed. The MIT license is preserved.

## Obsidian plugin watcher

Reviewed for catalog/indexing concepts. No license file was found and no watcher code was copied.

## TTRPG JSON folder

The supplied system-reference JSON files are included unchanged under `json/systems` for the user’s campaign library. Users remain responsible for their underlying content rights and redistribution choices.
