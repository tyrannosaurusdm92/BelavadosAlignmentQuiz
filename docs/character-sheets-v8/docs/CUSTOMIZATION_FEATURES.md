# Shared Character Studio Customization

All nine sheets use the same D&D Character Studio presentation and navigation layer.

## Layout and navigation

- Centered 960 px studio shell with responsive fallback.
- D&D-style header, toolbar, status strip, sticky sidebar, and main module column.
- Draggable 75 px hamburger menu copied from the supplied navigation reference.
- Jump list generated from each sheet’s actual sections.
- Keyboard access, Escape-to-close behavior, mobile placement, and print suppression.

## Artwork

- Two drag-and-drop image windows on every sheet: Character Portrait and Secondary Art.
- Click-to-upload and drag-and-drop support.
- Clear controls for both images.
- Images are stored in character autosave, JSON exports, reference bundles, and interactive HTML exports.

## Named sheet designs

- Original System Design
- Arcane Cyan
- Ember Parchment
- Verdant Ledger
- Royal Archive
- Steel & Ink
- Sunset Teal

The named designs use palette values adapted from the supplied color reference. Homebrew names and setting-specific terms were deliberately excluded.

## Additional controls

- Editable primary, secondary, page, text, and background colors.
- Background upload, background URL, no-image mode, default restoration, and darkening control.
- Appearance persistence is separate from character data but is embedded in interactive HTML exports.
- Header and hamburger design dropdowns remain synchronized.
