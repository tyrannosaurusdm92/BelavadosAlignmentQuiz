# License and Provenance Guide v9

Created By William Saville AKA The Transgender T-Rex #TheTransgenderTrex developer of Belavadös Galaxy TTRPG System

## Where to look

- `THIRD_PARTY_NOTICES.md` summarizes incorporated, adapted, referenced, and excluded projects.
- `licenses/` contains retained license and notice texts.
- `json/tablegate/provenance/source-provenance.json` is the machine-readable provenance catalog shown in **Data & Sources**.
- `source-readmes/` retains upstream project explanations where required for context.
- `source-code/` retains corresponding-source material, explicit source snapshots, and inactive prior-integration references where redistribution or auditability requires them. These files are not loaded by `tablegate.html`.
- `audits/` and top-level versioned audits retain historical integration and validation records.
- `MERGE_AUDIT_v9.md` explains how the supplied TableGate versions became this release.
- `PACKAGE_MANIFEST_v9.json` records file hashes and multipart assignments.

## Classification

An **Integrated** entry identifies local code/assets and its license. A **Reference** entry records research influence without copying code. An **Excluded** entry records why material was not redistributed. Historical validation files document prior states and do not override the current v9 reports.

## Redistribution reminder

Upstream names and trademarks remain with their owners. Review the corresponding license before removing notices or redistributing modified files. Independently verify rights for user-supplied artwork, tokens, fonts, audio, rules text, and campaign assets.
