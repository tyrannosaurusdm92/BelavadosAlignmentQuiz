# Licensing and Rules Boundary

TableGate integrates the user-supplied self-contained character sheets and complete reference JSON files. It does not add outside proprietary rule text.

The D&D source includes its own SRD/OGL/Creative Commons attribution and licensing notes. Other systems remain player aids based on the supplied references and may still require official books for full copyrighted option text, setting material, examples, and exceptions.

Powered by the Apocalypse is treated as a family of games through an exact-game adapter rather than a single universal ruleset. Blades in the Dark keeps Deep Cuts optional rather than silently mixing it into the original core baseline.


Character-system reference files retain the licensing and attribution notices embedded in their source JSON.

The packaged reference gold ring in `assets/token-borders/reference-gold-ring.png` was supplied by the project owner for this build. Its rights and reuse permissions remain with the project owner/source rights holder.
