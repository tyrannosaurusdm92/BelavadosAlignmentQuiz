# Licenses and Provenance v10

TableGate’s project-specific code and documentation retain the notices supplied in the source project. Third-party notices remain in `docs/github/licenses/third-party-notices.md`, `docs/github/licenses/copying-gpl-3-0.txt`, component READMEs, and source-specific manifests.

The nine-system JSON pack includes system-level content-policy fields and official licensing/reference URLs. Inclusion in this release does not convert proprietary game text into open content. Redistributors must preserve attribution, license files, provenance manifests, and any limits described in the system manifests.

The uploaded Apps Script backend is preserved as a reference/deployment source with no code changes. Its SHA-256 is `8a439d64e740e7f5e8eaf3cdcaa018b2966e7a999cd232742986c3be91accc67`.

The following categories are recorded separately in the file and code-usage manifests:

- active TableGate runtime;
- embedded project assets and tools;
- embedded JSON knowledge;
- documentation and audits;
- retained source references;
- tests;
- supplied backend reference.

Before a public release, review any user-supplied images, maps, fonts, character sheets, and reference imports for redistribution rights. The build process verifies integrity and documentation, not ownership of every user-supplied asset.
