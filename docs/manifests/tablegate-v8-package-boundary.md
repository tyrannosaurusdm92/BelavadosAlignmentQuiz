# TableGate V8 Package Boundary

The two delivery archives are complementary parts of one drag-and-drop update. They contain no duplicate project paths and should both be extracted into the existing TableGate repository root.

Included: only files that were added, changed, or translated by this update.

Excluded: backend source, unchanged images/SVGs, unchanged JSON and documentation libraries, unchanged AI-brain data, and every unchanged frontend file.

After extraction, follow `docs/update/DELETE_THESE_FILES.txt` to remove obsolete Paint by Number files that an overlay upload cannot delete.
