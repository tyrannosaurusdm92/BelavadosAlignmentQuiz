# Complete Options Library & DM/GM/MOL Homebrew Engine

Generated: 2026-07-29T19:59:31.590109+00:00

Every character sheet now includes a source-aware option catalog, manual/homebrew option builder, approval state, per-option effects, a safe formula calculator, base and derived values, field linking, local autosave, and JSON import/export.

## Scope and copyright boundary

Open/SRD content and option names are bundled where reusable. Proprietary books are represented by names/source indexes or live-catalog gateways rather than copied rule descriptions. Players may enter mechanics from books they lawfully own. Every system accepts DM/GM/MOL-approved homebrew.

## Formula engine

Supported operations are Add, Multiply, Set, Minimum, and Maximum. Values may be constants or formulas using any base/derived key. Supported functions: `min`, `max`, `floor`, `ceil`, `round`, and `abs`. Linked results can be pushed into detected sheet fields, and input/change events are dispatched so native calculations continue.
