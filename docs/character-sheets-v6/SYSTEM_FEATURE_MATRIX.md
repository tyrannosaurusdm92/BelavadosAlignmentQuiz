## Shared interface on every row

Every system uses the same D&D studio layout, two artwork windows, hamburger jump navigation, named design dropdown, live summary sidebar, quick-math guidance, local save/import/export, rules search, responsive layout, print support, and editable interactive HTML export.

## Added automation layer

Every row also includes the shared circular two-art editor, system-specific progression tracker and popup flow, currency/resource transaction ledger, live rules audit, and `tablegate.character-sheet.v1` future-portal bridge. The bridge never generates random dice.
