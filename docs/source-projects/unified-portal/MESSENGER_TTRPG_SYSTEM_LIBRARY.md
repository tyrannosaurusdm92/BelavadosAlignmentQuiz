# TTRPG system library

Open a campaign, then choose the **TTRPG system** book icon in the server rail.

1. Select a system, such as Pathfinder 2e, Call of Cthulhu 7e, or GURPS 4e.
2. Add optional comma-separated tags.
3. Drag JSON, PDF, DOCX, or TXT onto the drop window.
4. The backend stores the original file privately in Google Drive and records campaign-scoped metadata in the messenger database.
5. Indexable text is retained in the private `SystemDocuments` sheet for grounded search.

The assistant does not silently invent a rule. It returns matching source excerpts, document titles, system names, and manual page/section notes. Suggested dice expressions are convenience hints and should be verified against the cited source.

Copyright and licensing restrictions still apply to the files that campaign members upload. The application does not include proprietary game books.
