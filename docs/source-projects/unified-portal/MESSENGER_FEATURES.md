# Feature inventory

## Messenger and Discord-clone features

- Invite-only campaign servers and reusable/expiring invite links
- Server rail, categorized channels, member sidebar, responsive mobile drawers
- Text, announcement, handout, voice, and video channel types
- Direct messages, group DMs, direct calls, friends/search foundation
- Message editing, soft deletion, purge, replies, pins, reactions, attachments, mentions, typing, search, and unread tracking
- Creator, moderator, player, and custom role permissions
- Character personas and server-audited dice rolls
- Presence, notifications, polling gateway, audit log, and sound cues
- WebRTC voice/video signaling, push-to-talk, screen share, mute, and deafen

## Shared organizer

- Dashboard with next session, open tasks, pending approvals, and rules-file counts
- Shared task columns for to-do, in-progress, completed, and cancelled work
- Assignees, priorities, due dates, descriptions, and tags
- Month calendar and agenda
- Session proposals and ordinary life events
- Availability privacy levels
- Administrator approval and rejection queue

## Rules workspace

- Permissioned drag-and-drop uploads
- JSON/TXT/DOCX indexing and optional PDF conversion
- Organized system metadata and tags
- Manual rule notes and citations
- Grounded search assistant and dice-expression handoff
