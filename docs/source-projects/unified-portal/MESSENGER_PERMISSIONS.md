# Organizer and library permissions

The existing role editor automatically displays the new permissions.

- **Manage organizer** — edit or delete tasks created by other users.
- **Approve calendar** — approve or reject submitted sessions, availability, appointments, birthdays, and other events.
- **Upload system files** — add JSON, PDF, DOCX, and TXT to the server rules library. This is intentionally separate from ordinary chat attachment permission.
- **Manage system library** — reindex or remove system files.
- **View private availability** — view runner-only and private scheduling details.
- **Use rules assistant** — search indexed system documents and rule notes.

Every server member can submit a calendar item. A normal player sees their own pending submission, but it is not published fully to the party until an approver accepts it. Runner-only details are hidden from ordinary members even after approval.
