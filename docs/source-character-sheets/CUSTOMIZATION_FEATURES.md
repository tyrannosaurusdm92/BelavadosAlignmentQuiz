# Character Sheet Appearance Revision

All nine character-sheet HTML files include the same isolated appearance and navigation layer.

- Sheet Default plus generic Style 1 through Style 6 presets.
- Editable primary, secondary, page, text, and background colors.
- Background image upload with browser-side resizing, image URL support, no-image mode, default restoration, and darkening control.
- Per-sheet local persistence independent of character save data.
- Draggable floating jump bubble with a section list generated from each document.
- Keyboard-accessible controls, Escape-to-close behavior, mobile positioning, and print suppression.
- No Belavadös, ichor, deity, faction, settlement, or other homebrew-world material was copied into the sheets.
