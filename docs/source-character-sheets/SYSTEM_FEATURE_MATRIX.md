|---|---|---|---|---|
| Fate Core | Five aspects, skill pyramid/columns, stunt-to-Refresh validation | 4dF + skill; opposition, shifts, four actions, four outcomes | Escalating Core stress boxes and consequences | Stunts, invokes, compels, free invokes, boosts |
| GURPS 4e | Character-point ledger, attribute costs, secondary characteristics, skill difficulty/point levels | 3d6 roll-under, margin, critical success/failure, defense and damage/DR | HP, FP, encumbrance, injury prompts | Advantages, disadvantages, quirks, skills, techniques/notes |

## Shared appearance revision

Every listed sheet now includes Sheet Default plus Style 1–Style 6, individual color pickers, background image upload/URL/no-image/default controls, image darkening, local persistence, and a draggable section jump bubble. These controls are presentation-only and do not add setting-specific fields or rules.
